## 카테고리 가이드

- **사용자 지갑:** 모바일 앱, 브라우저 확장, 거래소 연동 지갑과 같은 전통적인 소비자용 지갑입니다. 사용자는 USDT를 보유하고, 이체하고, dApp에 연결하고, Stable과 직접 상호 작용할 수 있습니다.
- **지갑 SDK:** 개발자에게 지갑 생성, 키 관리, 트랜잭션 서명 및 블록체인 상호 작용을 애플리케이션에 직접 통합하기 위한 사전 구축된 도구, API 및 인프라를 제공하는 소프트웨어 개발 키트입니다.
- **Custodial / 기관 지갑:** 기관에 규제된 엔터프라이즈급 자산 보관을 제공하는 플랫폼입니다. 이러한 솔루션은 최종 사용자 흐름보다는 규정 준수, 거버넌스 제어, 안전한 키 관리 및 재무 운영에 중점을 둡니다.
- **임베디드 / 인앱 지갑:** SDK 또는 백엔드 시스템을 통해 애플리케이션 내부에 생성되는 지갑입니다. 주류 사용자가 외부 암호화 지갑을 설치하거나 이해할 필요 없이 원활한 온보딩을 가능하게 합니다.
- **스마트 지갑 / 계정 추상화:** 가스 없는 트랜잭션, 번들 작업 또는 자동 실행과 같은 사용자 정의 로직을 지원하는 프로그래밍 가능한 지갑입니다. 이러한 지갑은 개발자 정의 동작으로 기본 지갑 기능을 확장합니다.
- **MPC 지갑 제공업체:** 다자간 계산(MPC)을 사용하여 여러 당사자 또는 장치에 개인 키 제어를 분산시키는 키 관리 시스템입니다. 전통적인 시드 문구 없이 높은 보안 보관이 필요한 앱 또는 기업에 이상적입니다.
- **연결성 제공업체:** 지갑과 dApp을 연결하는 WalletConnect (Reown)와 같은 프로토콜입니다. 자산을 저장하거나 지갑 역할을 직접 수행하지 않고, 트랜잭션 서명 및 상호 작용을 위한 안전한 통신 채널을 제공합니다.

## 1. 사용자 지갑

이들은 주요 글로벌 거래소에서 제공하는 최종 사용자 지갑입니다. 사용자는 Stable에서 USDT를 보유하고, 자금을 이체하고, 애플리케이션에 연결할 수 있습니다.

### Stable Pay

Stable에 구축된 비custodial 결제 지갑으로, 빠르고 스테이블코인 기반 트랜잭션을 위해 설계되었습니다. Stable Pay는 즉각적인 USDT 결제, 예측 가능한 수수료, 일상적인 이체 및 상거래에 최적화된 간단한 사용자 경험을 제공합니다.

**기능**

- Stable용 비custodial 지갑
- 즉각적인 USDT 결제
- 예측 가능하고 일관된 거래 비용
- Stable의 USDT 기반 결제 계층에 직접 구축
- 결제 및 상거래를 위해 설계된 소비자 친화적인 UI

### 바이낸스 지갑

거래량 기준 세계 최대 거래소와 통합된 널리 사용되는 다중 체인 지갑입니다.

**기능**

- Stable USDT 지원
- 바이낸스 생태계와 직접 통합
- 모바일 및 확장 지갑 옵션

### Bitget Wallet

Bitget 거래소 생태계에 연결된 다중 자산 지갑으로, 암호화폐, 주식, ETF를 지원합니다.

**기능**

- Stable USDT 지원
- 내장 dApp 브라우저
- Bitget 거래 계정과 원활한 통합

### Gate Wallet (Gate Onchain)

글로벌 최대 현물 거래소 중 하나가 지원하는 지갑 제품입니다.

**기능**

- Stable USDT 지원
- Gate 거래소와 지갑 간의 쉬운 이체
- dApp 및 웹 앱 연결

### OKX Wallet (OKX Onchain)

전 세계적으로 사용되는 강력한 다중 체인 지갑입니다.

**기능**

- Stable USDT 지원
- 깊은 OKX 생태계 통합
- 웹, 모바일 및 확장 지갑 옵션

### Atomic Wallet

데스크톱, 모바일 및 브라우저 확장으로 제공되는 비수탁 다중 자산 지갑입니다. Atomic Wallet은 [Simplex by Nuvei](/ko/reference/ramps#simplex-by-nuvei) 온램프를 통합하여 사용자가 앱 내에서 카드, Apple Pay, Google Pay 또는 은행 송금을 통해 Stable에서 USDT를 직접 구매할 수 있습니다.

**기능**

- Stable에서 USDT를 보유하고, 보내고, 받을 수 있습니다.
- 개인 키는 사용자 장치에 로컬로 저장됩니다.
- Simplex를 통해 Stable에서 USDT를 구매하기 위한 인앱 구매 흐름
- Windows, macOS, Linux, iOS, Android 및 Chrome에서 사용 가능

**시작하기**: [atomicwallet.io](https://atomicwallet.io/downloads)에서 Atomic Wallet을 다운로드하고, Stable을 네트워크로 추가하고, 인앱 구매 흐름을 사용하여 Simplex를 통해 Stable에서 USDT를 구매하십시오.

### Gem Wallet

Stable을 기본적으로 지원하는 iOS 및 Android용 오픈소스 비수탁 다중 체인 모바일 지갑입니다. 사용자는 Stable에서 USDT0을 보유하고 보낼 수 있으며, Uniswap v3를 통해 USDT0과 STABLE을 스왑할 수 있으며, 네트워크 수수료는 USDT0으로 지불됩니다. Gem Wallet은 또한 Stable과 BNB Chain, Arbitrum, Base와 같은 다른 네트워크 간의 교차 체인 USDT0 스왑을 라우팅합니다.

**기능**

- Stable에서 USDT0을 보유하고, 보내고, 받을 수 있으며, 네트워크 수수료는 USDT0으로 지불됩니다.
- Uniswap v3를 통한 USDT0과 STABLE 간의 온체인 스왑
- Stable과 다른 네트워크 간의 교차 체인 USDT0 스왑
- 개인 키는 사용자 장치에 로컬로 저장됩니다. 계정, 이메일 또는 KYC가 필요하지 않습니다.
- [GitHub](https://github.com/gemwalletcom/wallet)의 오픈소스 코드

**시작하기**: [gemwallet.com/download/](https://gemwallet.com/download/)에서 [iOS](https://apps.apple.com/app/id6448712670) 또는 [Android](https://play.google.com/store/apps/details?id=com.gemwallet.android)용 Gem Wallet을 다운로드하십시오. Stable 주소는 지갑과 함께 자동으로 생성됩니다.

## 2. 지갑 SDK

### Tether의 개발 키트(WDK)

어떤 플랫폼과 블록체인에서도 자체 보관 지갑을 구축하기 위한 Tether의 오픈소스 SDK입니다.

**기능**

- 다중 체인 지원: 비트코인, 이더리움, TON, 트론, 솔라나, 스파크 등
- 에이전트 지갑: Stable의 AI 에이전트 지갑 및 x402 결제 기본 지원
- DeFi 통합: 스왑, 브리지, 대출 프로토콜을 위한 플러그인 지원
- 확장 가능한 디자인: 새로운 블록체인 또는 프로토콜을 위한 사용자 정의 모듈 추가

**시작하기**: [`@tetherto/wdk`](https://www.npmjs.com/package/@tetherto/wdk) 및 [`@tetherto/wdk-wallet-evm`](https://www.npmjs.com/package/@tetherto/wdk-wallet-evm)을 설치한 다음, [WDK 문서](https://docs.wallet.tether.io)를 따라 Stable을 대상 체인으로 구성하십시오.

## 3. Custodial 및 기관 지갑

### Anchorage

디지털 자산에 대한 기관 등급 보관을 제공하는 연방 인가 국립 은행입니다.

**기능**

- Stable USDT에 대한 보안 보관
- 완전한 규정 준수 및 규제 감독
- 엔터프라이즈급 키 관리 및 액세스 제어

## 4. 임베디드 / 인앱 지갑

SDK를 통해 애플리케이션에 직접 임베드되어 원활한 사용자 온보딩 및 결제 흐름을 가능하게 하는 지갑입니다.

### Coinbase Developer Platform (CDP)

CDP는 사용자 대면 앱 및 백엔드 시스템을 위한 비custodial 지갑을 제공합니다. 사용자 인증 지갑은 이메일, SMS 또는 소셜 로그인 기능을 사용합니다. API 키 지갑은 서버가 계정을 관리할 수 있도록 하며, CDP는 신뢰할 수 있는 실행 환경 내에서 개인 키를 보호합니다.

**기능**

- 시드 문구가 없는 임베디드 지갑
- 자동화된 워크플로 및 백엔드 서비스를 위한 API 키 지갑
- EVM 계정 생성 및 트랜잭션 서명
- 사용자 제어 지갑을 위한 키 내보내기

**Stable 통합**

Coinbase Wallet API는 모든 EVM 호환 네트워크를 지원하므로 Stable을 지원합니다. 체인 ID `988` 및 `https://rpc.stable.xyz`로 Stable을 구성하거나, CDP로 서명하고 Stable의 RPC를 통해 브로드캐스트하십시오.

Coinbase Onramp는 법정화폐-암호화폐 변환을 위한 별도의 제품이며 Stable을 지원하지 않습니다.

**시작하기**: [CDP 비custodial 지갑 문서](https://docs.cdp.coinbase.com/wallets/non-custodial-wallets/overview)를 따르고 사용자 인증 또는 API 키 퀵스타트를 선택하십시오.

### Dynamic

수천 개의 애플리케이션과 4천만 명 이상의 사용자에게 서비스를 제공하는 엔터프라이즈급 지갑 인프라입니다.

**기능**

- 지갑 생성 및 인증
- 임베디드 지갑 흐름
- 앱 및 핀테크를 위한 사용자 온보딩

**시작하기**: [Dynamic SDK 설정 문서](https://docs.dynamic.xyz/introduction/welcome)를 따라 SDK를 설치하고 Stable을 앱에서 지원되는 네트워크로 구성하십시오.

### Privy

Privy는 사용자, 조직, 재무부 및 에이전트를 위한 임베디드 지갑을 제공합니다. 지갑은 비custodial 또는 custodial 구성으로 사용할 수 있습니다.

**기능**

- 이메일, 소셜 로그인, 패스키 또는 외부 지갑으로 인증

- 비custodial 지갑을 위한 사용자 제어 키 내보내기

**시작하기**: [Privy 임베디드 지갑 문서](https://docs.privy.io/wallets/overview/embedded)를 따라 지갑을 생성한 다음, 앱에서 Stable을 EVM 네트워크로 구성하십시오.

### Portal

Portal은 웹, iOS, Android, React Native용 SDK와 서버 측 통합을 위한 API를 통해 MPC 지갑을 제공합니다. MPC(다자간 계산)는 서명 권한을 별도의 키 공유로 분할합니다.

**기능**

- 임베디드 EVM 지갑 생성, 백업 및 복구
- 메시지 및 트랜잭션 서명
- EVM 네트워크를 위한 사용자 정의 RPC 구성
- 웹, 모바일 및 API 통합 옵션

**시작하기**: [Portal SDK 퀵스타트](https://docs.portalhq.io/sdks/quickstart)를 따른 다음, `rpcConfig`에서 Stable의 CAIP-2 체인 ID (`eip155:988`)를 `https://rpc.stable.xyz`에 매핑하십시오.

### Turnkey

Turnkey는 TEE(신뢰할 수 있는 실행 환경) 내에서 서명 및 정책 평가를 통해 임베디드 지갑을 제공합니다. TEE는 서명 중 키를 보호하는 격리된 하드웨어 기반 환경입니다.

**기능**

- 이메일, 전화, 소셜 로그인, 패스키 또는 생체 인식으로 인증
- EVM 호환 네트워크 전반에 걸친 임베디드 지갑
- 비custodial, custodial 및 하이브리드 custodial 모델
- 프로그래밍 가능한 서명 정책 및 사용자별 격리

**시작하기**: [Turnkey 임베디드 지갑 개요](https://docs.turnkey.com/solutions/embedded-wallets/overview)를 따르고, SDK를 선택하고, Stable을 EVM 네트워크로 구성하십시오.

### Reown (이전 WalletConnect)

지갑을 애플리케이션에 연결하기 위한 널리 채택된 표준입니다.

**기능**

- 모바일, 데스크톱 및 확장 지갑 지원
- 광범위한 생태계 호환성

**지갑 온보딩을 위한 Reown SDK**

Stable은 **Reown SDK**와의 통합을 지원하여 개발자가 사용자에게 원활한 지갑 및 온보딩 경험을 제공할 수 있도록 돕습니다.

Reown은 WalletConnect 네트워크의 공식 게이트웨이 역할을 하는 오픈소스 올인원 SDK를 제공합니다. 이 SDK는 애플리케이션 내에서 원활한 지갑 연결, 트랜잭션, 로그인, 임베디드 지갑(이메일 및 소셜 로그인), 온체인 결제, 인앱 스왑 등을 가능하게 합니다.

**시작하기**

### Safe

세이프(Safe)는 설정된 수의 소유자가 승인한 후에만 트랜잭션을 실행하는 스마트 계약 계정입니다. 이를 m-of-n 멀티시그라고 합니다. 즉, n개의 소유자 중 m명이 서명해야 합니다. 소유자는 EOA, 하드웨어 지갑 또는 다른 세이프 계정이 될 수 있으며, 모듈 및 가드는 지출 한도 또는 복구와 같은 프로그래밍 가능한 로직을 추가합니다.

**기능**

- 구성 가능한 서명 임계값을 가진 멀티시그 스마트 계정
- 여러 호출이 하나의 트랜잭션에서 원자적으로 처리되도록 하는 일괄 트랜잭션
- 지출 정책, 복구 및 자동화를 위한 모듈 및 가드
- 새 주소로 자산을 이동하지 않고도 소유자 및 임계값 변경
- ERC-1271 계약 서명 및 오프체인 서명 수집
- 패스키 소유자, 즉 시드 문구 대신 장치 생체 인식 또는 보안 키로 세이프에 서명할 수 있습니다.
- Safe4337Module을 통한 ERC-4337 실행, 번들 사용자 작업 및 스폰서 가스용
- 계정 배포, 트랜잭션 제안 및 인덱싱을 위한 Safe\{Core\} SDK 키트

**Stable 통합**

Safe는 Safe\{Wallet\}, Safe\{Core\} SDK 및 Safe Transaction Service에서 Stable을 네트워크로 지원합니다. 체인 접두사는 `stable`이므로 Safe 주소는 `stable:0x...`로 작성되고 `https://app.safe.global`에서 열립니다. Stable용 Transaction Service는 `https://api.safe.global/tx-service/stable`에서 실행되며, 이는 chain ID `988`을 전달할 때 API Kit이 사용하는 것입니다.

캐노니컬 계약은 버전 1.3.0, 1.4.1 및 1.5.0에 대해 결정론적 주소에 배포되므로, Safe 주소를 하드코딩하는 도구는 사용자 정의 배포 없이 Stable에서 작동합니다. 1.4.1 주소는 다음과 같습니다.

| **계약** | **주소** |
| :----------------- | :------------------------------------------- |
| SafeProxyFactory | `0x4e1DCf7AD4e460CfD30791CCC4F9c8a4f820ec67` |
| Safe (싱글톤) | `0x41675C099F32341bf84BFc5382aF534df5C7461a` |
| SafeL2 (싱글톤) | `0x29fcB43b46531BcA003ddC8FCB67FFE91900C762` |
| MultiSendCallOnly | `0x9641d764fc13c8B624c04430C7356C1C7C8102e2` |

Stable에서 USDT0이 가스 자산이므로 첫 번째 트랜잭션 전에 USDT0으로 Safe에 자금을 조달하십시오.

**패스키**

패스키 소유자는 Safe를 대신하여 서명하는 장치 생체 인식 또는 보안 키와 같은 WebAuthn 자격 증명입니다. `SafeWebAuthnSignerFactory`는 자격 증명의 공개 키에 대한 서명자 계약을 배포하고, 해당 계약은 Safe 소유자로 추가됩니다. `SafeWebAuthnSharedSigner`는 자격 증명당 계약을 배포하지 않고 패스키 소유자를 원할 때의 대안입니다. 둘 다 Stable에 배포되어 있으며, 서명자 구성이 서명 확인을 위해 가리키는 Daimo P-256 검증자도 함께 배포됩니다.

**ERC-4337**

`Safe4337Module`은 Stable에 배포되어 모듈과 폴백 핸들러로 Safe에서 활성화됩니다. 이를 통해 계정은 ERC-4337 번들러를 통해 사용자 작업을 실행할 수 있으며, 스폰서 가스를 위한 선택적 페이마스터도 함께 사용할 수 있습니다. `SafeModuleSetup`은 Safe 배포 중에 모듈을 활성화합니다. 모듈은 EntryPoint v0.7을 대상으로 하며, EntryPoint v0.6도 이전 도구를 위해 배포됩니다.

**모듈 주소**

| **계약** | **주소** |
| :-------------------------- | :------------------------------------------- |
| Safe4337Module | `0x75cf11467937ce3F2f357CE24ffc3DBF8fD5c226` |
| SafeModuleSetup | `0x2dd68b007B46fBe91B9A7c3EDa5A7a1063cB5b47` |
| EntryPoint v0.7 | `0x0000000071727De22E5E9d8BAf0edAc6f37da032` |
| EntryPoint v0.6 | `0x5FF137D4b0FDCD49DcA30c7CF57E578a026d2789` |
| SafeWebAuthnSignerFactory | `0x1d31F259eE307358a26dFb23EB365939E8641195` |
| SafeWebAuthnSignerSingleton | `0x4E27b51350e6c2083EE19011120F50DAfEc5CA50` |
| SafeWebAuthnSharedSigner | `0x94a4F6affBd8975951142c3999aEAB7ecee555c2` |
| Daimo P-256 verifier | `0xc2b78104907F722DABAc4C69f826a522B2754De4` |

**시작하기**: [Safe\{Wallet\}](https://app.safe.global)에서 계정을 생성하고 네트워크로 Stable을 선택하거나, [Safe\{Core\} Protocol Kit](https://docs.safe.global/sdk/protocol-kit)를 `https://rpc.stable.xyz`와 함께 사용하여 자체 애플리케이션에서 Safe를 배포하고 운영하십시오.
