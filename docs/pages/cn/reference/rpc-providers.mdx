# RPC 提供商

支持 Stable 的 RPC 和开发者基础设施提供商。

## Alchemy

全球信赖的完整区块链开发平台。[Alchemy 入门](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable)

**功能**

- RPC + WebSocket 基础设施
- 监控仪表板
- 开发者 API 和 SDK

**入门**：在 [Alchemy 仪表板](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable)中创建一个 Stable 应用以获取 RPC URL，然后将其用作你的 JSON-RPC 端点。

## Chainstack

Chainstack 为 Stable 提供托管 RPC 节点。你可以通过 HTTPS 或 WebSocket 连接到已部署的节点。

**功能**

- 托管 RPC 节点
- HTTPS 和 WebSocket 端点
- 完整和归档节点访问

**入门**：在 [Chainstack 控制台](https://console.chainstack.com/)中创建一个项目，选择 Stable，然后部署一个节点。将其 HTTPS 或 WebSocket 端点复制到你的应用中。

## Goldsky Edge RPC

Goldsky Edge RPC 是 Stable 主网和测试网的托管 RPC 端点，从多个区域提供服务。它基于 [eRPC](https://github.com/erpc/erpc) 构建，这是一个开源 RPC 代理，你也可以自行运行。

**功能**

- HTTPS JSON-RPC 端点（无 WebSocket）
- 链数据缓存
- 使用情况、延迟和错误仪表板

**入门**：在 [Goldsky 仪表板](https://app.goldsky.com)中创建 API 密钥，然后向 `https://edge.goldsky.com/standard/evm/988?key=YOUR_KEY` 发送 JSON-RPC 请求。测试网使用链 ID `2201`。

## Tenderly

提供模拟、调试、监控和执行工具的全栈开发者平台。

**功能**

- 实时合约模拟
- 调试和追踪
- 开发者交易工作流

**入门**：在 [Tenderly 仪表板](https://tenderly.co/)中设置一个 Stable 项目，以访问你的合约的模拟、调试和交易追踪功能。
