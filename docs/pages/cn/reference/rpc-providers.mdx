# RPC 提供商

支持 Stable 的 RPC 和开发者基础设施提供商。

## 概览表

| **提供商** | **类别** | **文档 / 开始使用** | **说明** |
| :--- | :--- | :--- | :--- |
| [**Alchemy**](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable) | RPC + 开发者平台 | [开始使用 Alchemy](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable) | RPC、WebSocket、监控、SDK |
| [**Chainstack**](https://chainstack.com/) | RPC + 节点基础设施 | [开始使用 Chainstack](https://console.chainstack.com/) | 托管 RPC、WebSocket、完整节点和归档节点 |
| [**PublicNode**](https://publicnode.com) | 免费公共 RPC | [stable.publicnode.com](https://stable.publicnode.com) | EVM RPC 和 WebSocket、Cosmos RPC、REST 和 gRPC-Web |
| [**Tenderly**](https://tenderly.co/) | 模拟 + 调试 | [tenderly.co](https://tenderly.co/) | 实时模拟、追踪、交易工作流 |

## Alchemy

一个全球信赖的完整区块链开发平台。[开始使用 Alchemy](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable)

**功能**

- RPC + WebSocket 基础设施
- 监控仪表板
- 开发者 API 和 SDK

**开始使用**：在 [Alchemy 仪表板](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=stable)中创建一个 Stable 应用来获取 RPC URL，然后将其用作你的 JSON-RPC 端点。

## Chainstack

Chainstack 为 Stable 提供托管 RPC 节点。你可以通过 HTTPS 或 WebSocket 连接到已部署的节点。

**功能**

- 托管 RPC 节点
- HTTPS 和 WebSocket 端点
- 完整节点和归档节点访问

**开始使用**：在 [Chainstack 控制台](https://console.chainstack.com/)中创建一个项目，选择 Stable，然后部署一个节点。将其 HTTPS 或 WebSocket 端点复制到你的应用中。

## PublicNode

PublicNode by Allnodes 为 Stable 提供免费公共 RPC 端点，无需创建账户。

**功能**

- EVM JSON-RPC 和 WebSocket 端点，免费无需注册
- Cosmos RPC、REST 和 gRPC-Web 端点
- 修剪和归档节点快照位于 [publicnode.com/snapshots](https://www.publicnode.com/snapshots#stable)

**开始使用**：从 [stable.publicnode.com](https://stable.publicnode.com) 复制一个端点到你的应用中，例如 `https://stable-evm-rpc.publicnode.com` 用于 EVM JSON-RPC。

## Tenderly

一个全栈开发者平台，提供模拟、调试、监控和执行工具。

**功能**

- 实时合约模拟
- 调试和追踪
- 开发者交易工作流

**开始使用**：在 [Tenderly 仪表板](https://tenderly.co/)中设置一个 Stable 项目，以访问你的合约的模拟、调试和交易追踪功能。
