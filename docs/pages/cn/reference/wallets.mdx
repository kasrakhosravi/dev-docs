## 类别指南

- **用户钱包：** 这些是传统的面向消费者的钱包，例如移动应用程序、浏览器扩展程序或与交易所关联的钱包。它们允许用户持有 USDT、进行转账、连接到 dApp 并直接与 Stable 交互。
- **钱包 SDK：** 一种软件开发工具包，为开发人员提供预构建的工具、API 和基础设施，以将钱包创建、密钥管理、交易签名和区块链交互直接集成到其应用程序中。
- **托管 / 机构钱包：** 为机构提供受监管的、企业级资产托管的平台。这些解决方案侧重于合规性、治理控制、安全密钥管理和资金运营，而不是最终用户流程。
- **嵌入式 / 应用内钱包：** 通过 SDK 或后端系统在应用程序内部生成的钱包。这些功能使主流用户能够无缝入职，而无需安装或理解外部加密钱包。
- **智能钱包 / 账户抽象：** 支持自定义逻辑（如无 gas 交易、捆绑操作或自动执行）的可编程钱包。这些功能通过开发人员定义的行为扩展了基本的钱包功能。
- **MPC 钱包提供商：** 使用多方计算 (MPC) 将私钥控制分配给多个参与方或设备的密钥管理系统。非常适合需要高安全性托管而无需传统助记词的应用程序或企业。
- **连接提供商：** 连接钱包和 dApp 的协议，例如 WalletConnect (Reown)。它们不存储资产或充当钱包本身；相反，它们提供安全的通信渠道，用于交易签名和交互。

## 1. 用户钱包

这些是主要全球交易所提供的最终用户钱包。它们允许用户持有 USDT、转移资金并连接到 Stable 上的应用程序。

### Stable Pay

一个构建在 Stable 上的非托管支付钱包，专为快速、稳定币原生交易而设计。Stable Pay 提供即时 USDT 支付、可预测的费用以及针对日常转账和商务优化的简单用户体验。

**功能**

- Stable 的非托管钱包
- 即时 USDT 支付
- 可预测且一致的交易成本
- 直接构建在 Stable 的 USDT 原生结算层上
- 专为支付和商务设计的消费者友好型 UI

### 币安钱包

一个广泛使用的多链钱包，与全球交易量最大的交易所集成。

**功能**

- 支持 Stable USDT
- 与币安生态系统直接集成
- 移动和扩展钱包选项

### Bitget 钱包

与 Bitget 交易所生态系统连接的多资产钱包，支持加密货币、股票和 ETF。

**功能**

- 支持 Stable USDT
- 内置 dApp 浏览器
- 与 Bitget 交易账户无缝集成

### Gate 钱包 (Gate Onchain)

由全球最大的现货交易所之一支持的钱包产品。

**功能**

- 支持 Stable USDT
- Gate 交易所与钱包之间轻松转账
- dApp 和 Web 应用程序连接

### OKX 钱包 (OKX Onchain)

一款功能强大、全球使用的多链钱包。

**功能**

- 支持 Stable USDT
- 深度 OKX 生态系统集成
- Web、移动和扩展钱包选项

### Atomic Wallet

一款非托管多资产钱包，可在桌面、移动设备和作为浏览器扩展使用。Atomic Wallet 集成了 [Simplex by Nuvei](/cn/reference/ramps#simplex-by-nuvei) 入口，因此用户可以通过内置应用程序使用银行卡、Apple Pay、Google Pay 或银行转账直接在 Stable 上购买 USDT。

**功能**

- 在 Stable 上持有、发送和接收 USDT
- 私钥本地存储在用户设备上
- 通过 Simplex 在应用程序内购买 Stable 上的 USDT
- 可用于 Windows、macOS、Linux、iOS、Android 和 Chrome

**开始使用**：从 [atomicwallet.io](https://atomicwallet.io/downloads) 下载 Atomic Wallet，添加 Stable 作为网络，然后使用应用程序内的“购买”流程通过 Simplex 购买 Stable 上的 USDT。

### Gem Wallet

一款开源、非托管的多链移动钱包，适用于 iOS 和 Android，原生支持 Stable。用户可以在 Stable 上持有和发送 USDT0，并通过 Uniswap v3 在 USDT0 和 STABLE 之间进行兑换，网络费用以 USDT0 支付。Gem Wallet 还支持 Stable 与 BNB Chain、Arbitrum 和 Base 等其他网络之间的跨链 USDT0 兑换。

**功能**

- 在 Stable 上持有、发送和接收 USDT0，网络费用以 USDT0 支付
- 通过 Uniswap v3 在 USDT0 和 STABLE 之间进行链上兑换
- Stable 与其他网络之间的跨链 USDT0 兑换
- 私钥本地存储在用户设备上；无需账户、电子邮件或 KYC
- [GitHub](https://github.com/gemwalletcom/wallet) 上的开源代码

**开始使用**：从 [gemwallet.com/download/](https://gemwallet.com/download/) 下载适用于 [iOS](https://apps.apple.com/app/id6448712670) 或 [Android](https://play.google.com/store/apps/details?id=com.gemwallet.android) 的 Gem Wallet。您的 Stable 地址会随钱包自动创建。

## 2. 钱包 SDK

### Tether 钱包开发套件 (WDK)

Tether 的开源 SDK，用于在任何平台和区块链上构建自托管钱包。

**功能**

- 多链支持：比特币、以太坊、TON、TRON、Solana、Spark 等
- Agentic 钱包：原生支持 Stable 上的 AI agent 钱包和 x402 支付
- DeFi 集成：插入式支持兑换、桥接和借贷协议
- 可扩展设计：为新区块链或协议添加自定义模块

**开始使用**：安装 [`@tetherto/wdk`](https://www.npmjs.com/package/@tetherto/wdk) 和 [`@tetherto/wdk-wallet-evm`](https://www.npmjs.com/package/@tetherto/wdk-wallet-evm)，然后按照 [WDK 文档](https://docs.wallet.tether.io) 将 Stable 配置为您的目标链。

## 4. 嵌入式 / 应用内钱包

通过 SDK 直接嵌入到应用程序中的钱包，实现无缝的用户引导和支付流程。

### Coinbase Developer Platform (CDP)

CDP 为面向用户的应用程序和后端系统提供非托管钱包。用户认证钱包使用电子邮件、短信或社交登录。API 密钥钱包允许服务器管理账户，而 CDP 则在受信任的执行环境内保护私钥。

**功能**

- 无助记词的嵌入式钱包
- 用于自动化工作流和后端服务的 API 密钥钱包
- EVM 账户创建和交易签名
- 用户控制钱包的密钥导出

**Stable 集成**

Coinbase Wallet API 支持 Stable，因为它支持所有 EVM 兼容网络。使用链 ID `988` 和 `https://rpc.stable.xyz` 配置 Stable，或使用 CDP 签名并通过 Stable 的 RPC 进行广播。

Coinbase Onramp 是一个独立的法定货币到加密货币转换产品，不支持 Stable。

**开始使用**：遵循 [CDP 非托管钱包文档](https://docs.cdp.coinbase.com/wallets/non-custodial-wallets/overview)，并选择用户认证或 API 密钥快速入门。

### Dynamic

服务于数千个应用程序和超过 4000 万用户的企业级钱包基础设施。

**功能**

- 钱包创建和身份验证
- 嵌入式钱包流程
- 应用程序和金融科技的用户引导

**开始使用**：按照 [Dynamic SDK 设置文档](https://docs.dynamic.xyz/introduction/welcome) 安装 SDK 并在您的应用程序中将 Stable 配置为支持的网络。

### Privy

Privy 为用户、组织、财务部门和代理提供嵌入式钱包。钱包可以使用非托管或托管配置。

**功能**

- 使用电子邮件、社交登录、Passkey 或外部钱包进行身份验证
- 嵌入式 EVM 钱包创建和交易签名
- 签名者、接收者、合约和转账金额的策略控制
- 用户控制的非托管钱包密钥导出

**开始使用**：按照 [Privy 嵌入式钱包文档](https://docs.privy.io/wallets/overview/embedded) 创建钱包，然后在您的应用程序中将 Stable 配置为 EVM 网络。

### Portal

Portal 通过适用于 Web、iOS、Android 和 React Native 的 SDK 以及用于服务器端集成的 API 提供 MPC 钱包。MPC，即多方计算，将签名权限分配给独立的密钥份额。

**功能**

- 嵌入式 EVM 钱包创建、备份和恢复
- 消息和交易签名
- EVM 网络的自定义 RPC 配置
- Web、移动和 API 集成选项

**开始使用**：按照 [Portal SDK 快速入门](https://docs.portalhq.io/sdks/quickstart)，然后将 Stable 的 CAIP-2 链 ID (`eip155:988`) 映射到 `rpcConfig` 中的 `https://rpc.stable.xyz`。

### Turnkey

Turnkey 提供嵌入式钱包，并在受信任的执行环境 (TEE) 内进行签名和策略评估。TEE 是一个隔离的硬件支持环境，可在签名期间保护密钥。

**功能**

- 使用电子邮件、电话、社交登录、Passkey 或生物识别进行身份验证
- 跨 EVM 兼容网络的嵌入式钱包
- 非托管、托管和混合托管模型
- 可编程签名策略和每个用户的隔离

**开始使用**：按照 [Turnkey 嵌入式钱包概述](https://docs.turnkey.com/solutions/embedded-wallets/overview)，选择一个 SDK，并将 Stable 配置为 EVM 网络。

### Reown（前身为 WalletConnect）

一个广泛采用的连接钱包到应用程序的标准。

**功能**

- 安全的钱包到 dApp 连接
- 支持移动、桌面和扩展钱包
- 广泛的生态系统兼容性

**Reown SDK 用于钱包引导**

Stable 支持与 **Reown SDK** 集成，帮助开发人员为用户提供无缝的钱包和引导体验。

Reown 提供一个开源的一体化 SDK，作为 WalletConnect 网络的官方网关。它使您的应用程序能够实现流畅的钱包连接、交易、登录、嵌入式钱包（电子邮件和社交登录）、链上支付、应用内兑换等功能。

**开始使用**

- 访问 Reown 的文档：[https://docs.reown.com/overview](https://docs.reown.com/overview)

一个消费者级的账户抽象钱包，专为即时稳定币消费和支付而设计。
**功能**

- 基于 AA 的用户体验，具有智能钱包执行功能
- 跨任何链的一键支付
- 无助记词；安全的密钥恢复

### Safe

Safe 是一个智能合约账户，只有在指定数量的所有者批准后才能执行交易。这称为 m-of-n 多重签名：n 个所有者中的任意 m 个必须签名。所有者可以是 EOA、硬件钱包或其他 Safe 账户，模块和守卫可以添加可编程逻辑，例如消费限制或恢复。

**功能**

- 具有可配置签名阈值多重签名智能账户
- 批量交易，因此多个调用在一个交易中原子结算
- 用于消费策略、恢复和自动化的模块和守卫
- 无需将资产转移到新地址即可更改所有者和阈值
- ERC-1271 合约签名和链下签名收集
- Passkey 所有者，因此可以使用设备生物识别或安全密钥而不是助记词签署 Safe
- 通过 Safe4337Module 进行 ERC-4337 执行，用于捆绑用户操作和赞助 Gas 费
- 用于账户部署、交易提案和索引的 Safe\{Core\} SDK 套件

**Stable 集成**

Safe 在 Safe\{Wallet\}、Safe\{Core\} SDK 和 Safe Transaction Service 中支持 Stable 作为网络。链前缀是 `stable`，因此 Safe 地址写为 `stable:0x...` 并在 `https://app.safe.global` 打开。Stable 的 Transaction Service 在 `https://api.safe.global/tx-service/stable` 运行，这是您传入链 ID `988` 时 API Kit 使用的服务。

规范合约已部署到其确定性地址，版本包括 1.3.0、1.4.1 和 1.5.0，因此硬编码 Safe 地址的工具无需自定义部署即可在 Stable 上运行。1.4.1 地址如下：

**Passkey**

Passkey 所有者是一种 WebAuthn 凭证，例如设备生物识别或安全密钥，代表 Safe 签名。`SafeWebAuthnSignerFactory` 部署一个用于凭证公钥的签名者合约，然后该合约作为 Safe 所有者添加。当您想要一个无需为每个凭证部署合约的 Passkey 所有者时，`SafeWebAuthnSharedSigner` 是替代方案。两者都已部署在 Stable 上，以及 Daimo P-256 验证器，签名者配置指向该验证器进行签名检查。

**ERC-4337**

`Safe4337Module` 已部署在 Stable 上，并作为模块和回退处理器在 Safe 上启用，这使得账户能够通过 ERC-4337 Bundler 执行用户操作，并可选地使用 Paymaster 赞助 Gas 费。`SafeModuleSetup` 在 Safe 部署期间启用该模块。该模块的目标是 EntryPoint v0.7；EntryPoint v0.6 也已部署用于旧版工具。

## Stable 网络设置

### 将 Stable 添加到您的钱包

**网络参数：**

- **网络名称：** Stable
- **链 ID：** 988
- **货币：** USDT0
- **RPC URL：** https://rpc.stable.xyz
- **区块浏览器：** https://stablescan.xyz

### 构建钱包集成

您可以通过以下方式添加 Stable 支持：

- 通过 Stable RPC 启用签名和 Gas 估算
- 支持 USDT 原生转账
- 为 dApp 集成 WalletConnect
- 将 Stable 添加到链列表或元数据注册表
